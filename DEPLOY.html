🌐 Publicar o Dashboard PQRS na Internet

Guia passo a passo para hospedar o dashboard na Vercel — gratuito, em ~10 minutos, com URL própria acessível de qualquer dispositivo.

Por que Vercel?

  • ✅ Grátis para projetos pessoais (sem cartão de crédito)
  • ✅ Deploy em segundos com 1 clique
  • ✅ HTTPS automático (cadeado verde)
  • ✅ URL final fica seuapp.vercel.app (ou domínio próprio se quiser)
  • ✅ Atualizações automáticas — basta dar git push

📦 O que já está pronto

O projeto já tem tudo configurado:

  • vercel.json → headers de cache otimizados
  • .gitignore → ignora arquivos desnecessários
  • index.html, config.html, style.css, dashboard.js, config.js
⚠ O backend continua no Apps Script (Google). A Vercel só hospeda a interface visual. Os dados continuam vindo da sua URL atual de Apps Script — você não precisa migrar nada do Google.

🚀 Caminho rápido (recomendado): GitHub + Vercel

1Criar conta no GitHub (se ainda não tem)

Acesse github.com/signup e crie uma conta com seu email. Demora 2 minutos.

2Instalar o GitHub Desktop

Baixe em desktop.github.com — é o jeito mais fácil de subir os arquivos sem usar terminal.

Faça login com sua conta GitHub.

3Criar repositório a partir da pasta do projeto

  1. Abra o GitHub Desktop
  2. Menu File → Add local repository
  3. Escolha a pasta C:\Users\Advogada\pqrs-dashboard
  4. Se aparecer "This directory does not appear to be a Git repository", clique em "create a repository"
  5. Preencha:
    • Name: pqrs-dashboard
    • Local Path: já está preenchido
    • Deixe os demais campos em branco
  6. Clique em "Create Repository"
  7. No canto inferior esquerdo, escreva um Summary qualquer (ex: "versão inicial") e clique em "Commit to main"
  8. No topo, clique em "Publish repository"
  9. Desmarque "Keep this code private" se quiser (Vercel grátis também aceita repositórios privados, então pode deixar marcado se preferir)
  10. Clique "Publish Repository"

Pronto — seus arquivos estão no GitHub.

4Conectar Vercel ao GitHub

  1. Acesse vercel.com/signup
  2. Clique em "Continue with GitHub" e autorize
  3. Você cai no dashboard da Vercel
  4. Clique em "Add New..." → "Project"
  5. Localize pqrs-dashboard e clique em "Import"
  6. Deixe TUDO no padrão (não mexa em build, output, etc — é um site estático)
  7. Clique em "Deploy"

Espere ~30 segundos. Vai aparecer fogos de artifício e uma URL tipo pqrs-dashboard-xxx.vercel.app.

5Testar

Abra a URL no celular, na TV, em outro computador — o dashboard carrega normalmente e puxa os dados do Pipedrive em tempo real.

A URL seuapp.vercel.app/config.html abre as configurações.

✅ Pronto! Dashboard 100% acessível da internet. Toque para fixar na tela inicial do celular como se fosse um app, ou aponte a SmartTV para essa URL.

🔄 Como atualizar depois?

Quando você (ou eu, no Claude Code) editar qualquer arquivo do projeto:

  1. Abra o GitHub Desktop
  2. Você verá os arquivos modificados na coluna esquerda
  3. Escreva um Summary (ex: "ajuste de cor") e clique em "Commit to main"
  4. Clique em "Push origin" no topo

A Vercel detecta automaticamente e redeploya em ~20 segundos. Sua URL fica atualizada sozinha.

🎨 Quero um domínio personalizado?

Se quiser dashboard.suaempresa.com.br ao invés de vercel.app:

  1. Compre o domínio em Registro.br ou GoDaddy (~R$ 40/ano)
  2. Na Vercel: Project Settings → Domains → Add
  3. Digite o domínio que você comprou
  4. Vercel mostra 2 registros DNS para você adicionar no painel do seu domínio
  5. Em alguns minutos, o domínio fica funcionando com HTTPS automático

📺 Para a TV da sala

Modo recomendado:

  1. Use um Chromecast ou Fire TV Stick conectado à TV
  2. Abra a URL seuapp.vercel.app no Chrome do computador
  3. Clique nos 3 pontos → "Cast" → escolha a TV
  4. Ative o modo Tela Cheia (F11)

Ou, se a TV for SmartTV moderna com navegador:

  1. Abra o navegador da TV
  2. Digite a URL diretamente
  3. Ative tela cheia

🆘 Problemas comuns

"Não consigo abrir a URL"

Espere 1 minuto após o deploy. Se ainda não abrir, na Vercel veja a aba Deployments — clique no último deploy e veja se aparece "Ready" (verde).

"O dashboard carrega vazio na internet"

Verifique se o config.js tem a URL correta do Apps Script (a mesma que funciona localmente). Se sim, está tudo certo.

"Quero esconder a URL de visitas externas"

Na Vercel, vá em Project Settings → Deployment Protection e ative "Vercel Authentication". Só quem você convidar verá o dashboard.
