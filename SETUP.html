PQRS Dashboard

Guia de Instalação — versão com API do Pipedrive (zero delay)

⚠ Não abra os arquivos HTML do dashboard antes de terminar todos os passos abaixo. Você verá erros. É normal — o sistema precisa do backend configurado primeiro.

Ordem de instalação

[1] Pegar o TOKEN da API no Pipedrive
↓
[2] Descobrir os IDs dos funis no Apps Script
↓
[3] Editar o Code.gs com token + IDs
↓
[4] Publicar o Apps Script como Web App
↓
[5] Configurar webhook no Pipedrive
↓
[6] Hospedar dashboard no Vercel (internet) recomendado
↓
[7] Cadastrar vendedoras no painel
↓
[8] Abrir na TV em modo kiosk
1

Token da API do Pipedrive

  1. No Pipedrive, clique no seu nome (canto superior direito) → Configurações
  2. Preferências pessoais → aba API
  3. Copie o Token pessoal da API
⚠ Esse token dá acesso total à sua conta. Não compartilhe. Vai ficar dentro do Apps Script (privado).
2

Colar o Code.gs na planilha

  1. Abra sua planilha do Google
  2. Menu: Extensões → Apps Script
  3. Apague qualquer código existente
  4. Abra o arquivo apps-script/Code.gs (está na pasta pqrs-dashboard) com o Bloco de Notas
  5. Copie tudo e cole no editor do Apps Script
  6. Encontre a linha abaixo e substitua pelo seu token:
const PIPEDRIVE_TOKEN = 'COLE_AQUI_SEU_TOKEN_DO_PIPEDRIVE';

Confirme também que o domínio está correto (parte antes de .pipedrive.com da URL):

const PIPEDRIVE_DOMAIN = 'patezqueirozronconiestrauch';

Salve com Ctrl+S.

3

Descobrir IDs dos Funis

  1. No editor do Apps Script, no menu suspenso de funções, selecione descobrirFunis
  2. Clique em Executar
  3. Na primeira vez vai pedir autorização — clique em Autorizar acesso e aceite
  4. Abra os logs: menu Visualizar → Registros (ou Ctrl+Enter)
  5. Você vai ver algo como: 
    1: 1. Trabalhista
2: 2. Servidor Público
  6. Anote os números (IDs) de "1. Trabalhista" e "2. Servidor Público"
  7. Volte no código e edite: 
    const PIPELINE_TRABALHISTA_ID = 1;  // ← coloque o número real
const PIPELINE_SERVIDOR_ID = 2;     // ← coloque o número real

Descobrir nomes exatos das vendedoras

  1. Execute a função descobrirUsuarios
  2. Veja nos logs os nomes das usuárias do Pipedrive
  3. Esses nomes devem bater exatamente com os da aba "Vendedores" da planilha

Testar tudo

  1. Execute testarDashboard
  2. Deve aparecer nos logs: 
    Total deals analisados: 614
Contratos mês: 20
Leads mês: 614
Conversão: 3.26%
✅ Se aparecer números, a integração com o Pipedrive está funcionando!
4

Publicar como Web App

  1. No editor do Apps Script: Implantar → Nova implantação
  2. Clique no ícone de engrenagem ⚙ ao lado de "Selecione tipo" → escolha App da Web
  3. Configure:
    • Descrição: PQRS Dashboard v2
    • Executar como: Eu mesmo
    • Quem pode acessar: Qualquer pessoa ← obrigatório
  4. Clique em Implantar
  5. Copie a URL gerada (formato: https://script.google.com/macros/s/AKfycby.../exec)

Testar a URL

Abra no navegador: [SUA URL]/exec?action=ping

Deve aparecer: {"ok":true,"time":"...","domain":"patezqueirozronconiestrauch"}

⚠ Toda vez que alterar o código do Apps Script, vá em "Gerenciar implantações" → Editar → "Nova versão" → Implantar. Senão a URL continua com a versão antiga.
5

Colar a URL no dashboard

Abra o arquivo config.js com o Bloco de Notas e substitua a linha:

APPS_SCRIPT_URL: 'COLE_AQUI_A_URL_DO_SEU_APPS_SCRIPT',

pela URL copiada no passo anterior:

APPS_SCRIPT_URL: 'https://script.google.com/macros/s/SEU_ID/exec',

Salve o arquivo.

6

Configurar Webhook no Pipedrive

  1. No Pipedrive: Configurações → Ferramentas e aplicativos → Webhooks
  2. Clique em + Webhook
  3. Configure:
    • URL do endpoint: cole a URL do Apps Script (mesma do passo 4)
    • Versão HTTP: v2
    • Tipo de evento: change.deal
    • Autenticação: nenhuma
  4. Salve

Testar o webhook

  1. Pegue um negócio do funil "1. Trabalhista" em aberto
  2. Marque como Ganho
  3. Em ~5 segundos, deve aparecer uma linha nova na aba Eventos da planilha
✅ Se a linha apareceu, o webhook está funcionando!
7

Hospedar no Vercel (internet) Recomendado

O Vercel é gratuito e deixa o dashboard acessível de qualquer lugar (celular, TV, qualquer PC).

  1. Crie conta em vercel.com com sua conta Google
  2. Clique em Add New → Project
  3. Escolha "Browse All Templates" → Import From Folder
  4. Arraste a pasta pqrs-dashboard (sem a subpasta apps-script)
  5. Clique em Deploy
  6. Em ~30 segundos você recebe uma URL como pqrs-dashboard.vercel.app
✅ Agora o dashboard é acessível de qualquer lugar!

Testar antes de subir (opcional)

Com a URL do Apps Script já no config.js, abra o index.html diretamente no navegador. Se os dados aparecerem, está ok para subir no Vercel.

8

Cadastrar Vendedoras

Acesse https://sua-url.vercel.app/config.html e configure:

  • Meta do mês (ex: 90)
  • Para cada vendedora:
    • Nome: deve bater EXATAMENTE com o nome no Pipedrive
    • Foto: URL pública da imagem (Google Drive compartilhado, Imgur, etc.)
    • Área: Trabalhista ou Servidor Público
    • Meta/dia: contratos esperados por dia

URL de foto via Google Drive

  1. No Google Drive, clique direito na foto → Compartilhar → Qualquer pessoa com o link
  2. Copie o link. Ele vai ser tipo: https://drive.google.com/file/d/FILE_ID/view
  3. Transforme para URL direta: https://drive.google.com/uc?id=FILE_ID
  4. Cole no campo Foto
9

Exibir na TV

Modo kiosk (recomendado)

Execute no PowerShell ou Executar (Win+R):

chrome.exe --kiosk https://sua-url.vercel.app

Para sair do modo kiosk: Alt+F4

Modo simples

  1. Abra o Chrome e acesse a URL do dashboard
  2. Pressione F11 para tela cheia

Atalhos do dashboard

  • T — disparar celebração de teste
  • N — pular para próximo slide
  • F11 — tela cheia
  • F5 — recarregar

Solução de Problemas

Dashboard mostra "URL do Apps Script não configurada"

Edite o arquivo config.js com o Bloco de Notas e cole a URL do Apps Script.

Dashboard carrega mas mostra tudo zerado

  • Execute descobrirUsuarios no Apps Script e confira se os nomes batem com a aba Vendedores
  • Confira se os IDs dos funis estão corretos

Webhook não dispara celebração

  • Veja na aba Eventos da planilha se apareceu linha nova
  • Se não: Pipedrive → Webhooks → Histórico → veja o erro

Som de sino não toca

Clique uma vez na janela do dashboard. Browsers bloqueiam áudio sem interação do usuário. Depois do primeiro clique funciona normalmente.
